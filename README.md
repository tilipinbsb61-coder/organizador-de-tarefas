# 📋 Organizador de Tarefas

* **Disciplina:** Engenharia de Software
* **Curso:** Análise e Desenvolvimento de Sistemas (ADS)
* **Tipo de trabalho:** Projeto acadêmico em grupo

## 📌 1. Sobre o Projeto
O **Organizador de Tarefas** é um sistema web desenvolvido como projeto acadêmico para facilitar o gerenciamento das atividades do dia a dia em uma interface simples e intuitiva.

## 🎯 2. Objetivo Geral
Aplicar conceitos de Engenharia de Software por meio da criação de uma aplicação funcional, da documentação do projeto e do uso do Git e GitHub para controle de versão e colaboração.

## ⚙️ 3. Funcionalidades
* Cadastro de novas tarefas.
* Visualização das tarefas cadastradas.
* Organização e acompanhamento das atividades.
* Marcar tarefas como concluídas e excluir tarefas.

## 🛠️ 4. Tecnologias Utilizadas
* **HTML5:** Estrutura da página.
* **CSS3:** Estilização e identidade visual.
* **JavaScript:** Funcionalidades e interatividade da aplicação.
* **Git e GitHub:** Controle de versão e colaboração.

## 📂 5. Estrutura dos Arquivos
* `index.html`: Estrutura principal da página.
* `style.css`: Estilos e layout.
* `script.js`: Lógica e funcionalidades da aplicação.
* `README.md`: Documentação do projeto.
